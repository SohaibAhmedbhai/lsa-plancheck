LSA-Plancheck – automatisierte Prüfung von Signalzeitenplänen

Bevor ein Signalprogramm ins Steuergerät geht, muss es sicher sein. LSA-Plancheck prüft es automatisch auf Konfliktfreiheit, Zwischenzeiten, Mindestfreigabezeiten sowie Gelb- und Rot-Gelb-Zeiten und erzeugt den Prüfbericht als Teil der Dokumentation.

English: A Python tool that checks traffic signal timing plans for conflicts, intergreen times and minimum green times before they are loaded into the controller, and writes the test report automatically.

Prüfbericht ansehen: Entwurf mit Fehlern Prüfbericht: korrektes Programm Code auf GitHub

Was geprüft wird

KonfliktfreiheitFeindliche Signalgruppen dürfen nie gleichzeitig Grün haben.
ZwischenzeitenBerechnet aus Räum- und Einfahrwegen, geprüft für jeden Phasenübergang.
MindestfreigabezeitenKeine Freigabe kürzer als vorgegeben (Standard 5 s).
Gelb und Rot-GelbGelbzeit passend zur zulässigen Geschwindigkeit (3 / 4 / 5 s).

Insgesamt 14 Prüfregeln, auch für Freigaben über das Umlaufende hinaus. Jeder Verstoß wird mit Ist-Wert, Soll-Wert und Fehlbetrag gemeldet.

So funktioniert es

  1. Knotenpunkt beschreiben – Signalgruppen, Konfliktgeometrie und Signalprogramme als Excel-kompatible CSV-Dateien (Beispieldateien).
  2. Zwischenzeiten berechnen – nach RiLSA 2015:
    tz = tü + (sr + lFz) / vr − se / ve  → Zwischenzeitenmatrix
  3. Programme prüfen – 14 Regeln, Fehler mit Ist/Soll-Vergleich.
  4. Bericht erzeugen – HTML, Markdown, JSON und Signalzeitenplan mit markierten Verstößen.

Diese Seite wird bei jeder Änderung am Code automatisch neu erzeugt: GitHub Actions führt das Tool aus und veröffentlicht die aktuellen Berichte. 17 automatisierte Tests sichern die Berechnung ab.
